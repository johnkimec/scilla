# Skills

Each skill is a folder with a `SKILL.md`. Run one by name. The steps live in that file.

| Command | When to use it |
|---|---|
| `/create-verification-skill` | Generate a project skill that launches the app, drives it the way a user would, and seeds a feature map. |
| `/maintain-verification-skill` | Check that feature map against the app and drive every feature once. |
| `/eval` | Run a blinded check of whether a skill or prompt change actually changes what agents do. |
